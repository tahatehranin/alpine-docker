# alpine-docker

یک ایمیج داکر سبک مبتنی بر [Alpine Linux](https://www.alpinelinux.org/) که سرور OpenSSH را اجرا می‌کند و امکان دسترسی از راه دور (از جمله از طریق پورت ۸۰) را فراهم می‌سازد.

## ویژگی‌ها

- پایه‌ی بسیار سبک با استفاده از `alpine:latest`
- نصب و راه‌اندازی خودکار OpenSSH Server
- تولید کلیدهای host به صورت خودکار
- ایجاد کاربر `tunnel` با رمز عبور
- پیکربندی سفارشی `sshd` روی پورت ۸۰ با پشتیبانی از احراز هویت رمز عبور و کلید عمومی

## ساختار پروژه

| فایل | توضیح |
| --- | --- |
| `Dockerfile` | تعریف ایمیج داکر و نصب SSH |
| `LICENSE` | مجوز MIT |
| `.gitignore` | فایل‌های نادیده گرفته شده توسط Git |

## ساخت ایمیج

```bash
docker build -t alpine-docker .
```

## اجرای کانتینر

```bash
docker run -d -p 80:80 --name alpine-ssh alpine-docker
```

سپس می‌توانید با استفاده از SSH به کانتینر متصل شوید:

```bash
ssh tunnel@localhost -p 80
```

رمز عبور پیش‌فرض کاربر `tunnel` برابر با `password` است.

## نکات امنیتی

- رمز عبور پیش‌فرض را پیش از استفاده در محیط‌های واقعی تغییر دهید.
- در صورت نیاز به ورود کاربر `root`، خط مربوطه در `Dockerfile` را از حالت کامنت خارج کنید.
- این پیکربندی برای اهداف آزمایشی/تونلینگ در نظر گرفته شده است.
